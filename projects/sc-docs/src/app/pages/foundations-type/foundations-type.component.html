Tipografía

Escala redonda en rem sobre root 16 (font-size-300 = 16px = 1rem exacto), step-named (mismo idioma que el Kit Pro y los devs) y desacoplada de la escala de espaciado. 8 tamaños + 7 line-heights.

El 14 y el 16 no son lo mismo. El DS no pisa el root del navegador (html se queda en 100%), así que 1rem = 16px y la rampa cae en píxeles redondos. El 14 que se ve por todo el sistema es el otro eje: es la base de la escala de espaciado (--sc-scale-1 = 14px, el sufijo es el multiplicador) y el tamaño del cuerpo por defecto (font-size-200). Bajar el root a 14 encogería los dos ejes a la vez.

    @for (s of sizes; track s.step) {

  • {{ s.sample }}

    font-size-{{ s.step }} {{ s.px }}px · {{ s.rem }}rem
    • }

Line-heights

    @for (l of lineHeights; track l.step) {
  • line-height-{{ l.step }} {{ l.px }}px · {{ l.rem }}rem
    • }

Pesos

    @for (w of weights; track w.name) {
  • font-weight-{{ w.key }} {{ w.name }} · {{ w.value }}
    • }

Naming por step (100…800), no por valor: el nombre no miente si el valor cambia, y Figma, código y los devs hablan el mismo idioma. En rem para que la letra escale con el tamaño base del navegador (accesibilidad). En CSS hay además font-size-50/75/600/700/900: son snaps, pasos que el Kit no trae y que se pegan al vecino para que el naming por step no deje huecos.
