Tema PrimeNG

Primitivos PrimeNG estilados por el preset (cada slot resuelve a var(--sc-*)).

Aura es la base

El preset es definePreset(Aura, …): parte de Aura tal cual sale de PrimeNG, y encima van tres capas. Lo que una capa no dice, lo pone la de debajo.

  1. Aura (@primeuix/themes/aura): todo lo que no decimos nosotros. La tabla va entera con Aura.
  2. La marca (sc-preset/*.ts): colores, medidas y radios del Kit de Figma, cada uno a var(--sc-*).
  3. El comportamiento (sc-preset/css.ts): lo que Aura no trae, como que una fila solo se ilumine si se puede pulsar.

Para un equipo que ya usa PrimeNG con Aura, cargar este preset cambia la marca, no la estructura: las plantillas de primeng.dev se usan tal cual.
